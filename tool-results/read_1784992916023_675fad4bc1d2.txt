    24→# 1. Platform Philosophy
    25→
    26→## Core Principle: Candidate Empowerment, Not Disqualification
    27→
    28→Our platform is designed to **open doors** for job seekers, not close them.
    29→
    30→### The Kenyan Reality:
    31→- A graduate may work multiple jobs for survival
    32→- A BCom graduate might be: Cashier (Today) → Teller (Next Year) → Auditor (Following Year)
    33→- Job seekers have **multiple professional identities**, not one fixed career path
    34→
    35→### What We Do:
    36→- Acknowledge all work experiences as valid
    37→- Present jobs that match **ANY** of the candidate's experiences
    38→- Allow candidates to choose up to **3 career trajectories** to focus on
    39→- Never disqualify candidates based on missing constraints
    40→- Let candidates decide if they meet administrative requirements (e.g., driving license, age)
    41→- Rank jobs so best matches appear first, but all matching jobs are visible
    42→
    43→### What We Don't Do:
    44→- Penalize candidates for having unknown employers
    45→- Lock candidates into a single career path
    46→- Use hard filters that reject candidates
    47→- Extract or rely on ambiguous data like company sector from CVs
    48→- Match on administrative requirements (license, age, nationality, languages)
    49→- Force candidates into rigid career categories

    53→# 2. System Architecture
    54→
    55→## 2.1 The "Extract Once, Compute Many" Approach
    56→
    57→**Key Decision:** LLM fires **ONCE** for CV parsing and **ONCE** for JD parsing. All matching happens in the database/backend using structured data.
    58→
    59→### Why This Approach:
    60→
    61→| Factor | Traditional (LLM Every Time) | Our Approach (Extract Once) |
    62→|--------|------------------------------|------------------------------|
    63→| **Cost** | $0.001 per match | $0.001 per upload + $0 for matches |
    64→| **Speed** | Slow (LLM latency) | Instant (DB query) |
    65→| **Scalability** | Linear cost scaling | Fixed cost per upload |
    66→| **Accuracy** | Inconsistent (LLM varies) | Deterministic (math) |
    67→

   323→# 4. Data Normalization & Enums
   324→
   325→## 4.1 Why Normalization Matters
   326→
   327→Without normalization, the same concept appears in multiple forms:
   328→
   329→| Raw LLM Output | Issue |
   330→|----------------|-------|
   331→| "BSc", "B.Sc", "Bachelor of Science", "Bachelors" | 4 variations of "Bachelor" |
   332→| "Admin", "Administration", "Office Admin" | 3 variations of "Administration" |
   333→| "Telco", "Telecom", "Telecommunications" | 3 variations of "Telecommunications" |
   334→
   335→**Normalization** maps all variations to a single canonical value.
   336→

   410→## 4.6 Normalization Pipeline
   411→
   412→### Step-by-Step Flow:
   413→
   414→```
   415→LLM Output (Raw JSON)
   416→      |
   417→      ▼
   418→┌─────────────────────────────────────────────────────────────┐
   419→│  normalize_candidate(raw_json):                            │
   420→│                                                             │
   421→│  1. Normalize education.level                              │
   422→│     "BSc" → "Bachelor"                                    │
   423→│                                                             │
   424→│  2. Normalize work_experience[].function                   │
   425→│     "Admin Assistant" → "Administration"                  │
   426→│                                                             │
   427→│  3. De-duplicate skills per cluster                        │
   428→│     ["Excel", "Excel"] → ["Excel"]                        │
   429→│                                                             │
   430→│  4. Calculate years_experience per cluster                 │
   431→│     From start/end dates of jobs                           │
   432→│                                                             │
   433→│  5. Validate and clean strings                             │
   434→└─────────────────────────────────────────────────────────────┘
   435→      |
   436→      ▼
   437→Stored in Database (Clean Enums)
   438→```
   439→
   440→### Implementation:
   441→
   442→```javascript
   443→// Next.js API Route - normalization helper
   444→function normalizeEducationLevel(rawLevel) {
   445→    if (!rawLevel) return null;
   446→    const lower = rawLevel.toLowerCase().trim();
   447→    
   448→    for (const [canonical, variations] of Object.entries(EDUCATION_LEVEL_ENUMS)) {
   449→        for (const variation of variations) {
   450→            if (lower.includes(variation)) {
   451→                return canonical;
   452→            }
   453→        }
   454→    }
   455→    return "None"; // Default
   456→}
   457→
   458→function normalizeFunction(rawFunction) {
   459→    if (!rawFunction) return "Other";
   460→    const lower = rawFunction.toLowerCase().trim();
   461→    
   462→    for (const [canonical, variations] of Object.entries(FUNCTION_ENUMS)) {
   463→        for (const variation of variations) {
   464→            if (lower.includes(variation)) {
   465→                return canonical;
   466→            }
   467→        }
   468→    }
   469→    return "Other";
   470→}
   471→
   472→function normalizeJob(rawJson) {
   473→    // Normalize fields
   474→    rawJson.job.job_function = normalizeFunction(rawJson.job.job_function);
   475→    rawJson.job.sector = normalizeSector(rawJson.job.sector);
   476→    rawJson.job.required_education.level = normalizeEducationLevel(
   477→        rawJson.job.required_education.level
   478→    );
   479→    return rawJson;
   480→}
   481→```

   485→# 5. LLM Extraction
   486→
   487→## 5.1 Technology Choice: LLM-Based Extraction
   488→
   489→**Why LLM over Regex?**
   490→
   491→| Challenge | Regex/NLP | LLM |
   492→|-----------|-----------|-----|
   493→| Messy formatting (tables, columns) | ❌ Breaks | ✅ Handles naturally |
   494→| Inconsistent headers | ❌ Requires exhaustive rules | ✅ Understands context |
   495→| Skills scattered across sections | ❌ Difficult to capture | ✅ Extracts from anywhere |
   496→| Dates in various formats | ❌ Complex parsing | ✅ Standardizes output |
   497→| Context understanding | ❌ Ambiguous | ✅ Infers correctly |
   498→
   499→**Recommended LLM:**
   500→- **Gemini 1.5 Flash** or **GPT-4o-mini**
   501→- Low cost (~$0.001 per CV)
   502→- Fast processing (2-5 seconds)
   503→- Large context windows (1M+ tokens)
   504→
   505→## 5.2 CV Extraction Prompt
   506→
   507→```
   508→You are an expert CV parser. Extract structured information from the following Kenyan CV.
   509→
   510→Extract the following JSON structure:
   511→
   512→{
   513→  "profile": {
   514→    "full_name": "string",
   515→    "phone": "string",
   516→    "email": "string",
   517→    "location": "string"
   518→  },
   519→  "education": {
   520→    "level": "string (PhD|Masters|Bachelor|Diploma|Certificate|None)",
   521→    "field": "string",
   522→    "institution": "string",
   523→    "start_year": "YYYY",
   524→    "end_year": "YYYY"
   525→  },
   526→  "work_experience": [
   527→    {
   528→      "function": "string (Administration|Finance|IT|Engineering|Sales|Marketing|Healthcare|Education|Hospitality|Logistics|Legal|Customer Service|Operations|Human Resources|Other)",
   529→      "job_titles": ["string"],
   530→      "skills": ["string"],
   531→      "years_experience": "number",
   532→      "representative_company": "string (optional)"
   533→    }
   534→  ],
   535→  "extras": {
   536→    "certifications": [{"name": "string", "institution": "string", "year": "YYYY"}],
   537→    "referees": [{"name": "string", "title": "string", "company": "string", "phone": "string", "email": "string"}],
   538→    "languages": ["string"],
   539→    "professional_memberships": ["string"],
   540→    "trainings": [{"name": "string", "institution": "string", "year": "YYYY"}]
   541→  }
   542→}
   543→
   544→Instructions:
   545→1. Group similar job experiences into clusters based on function
   546→2. Extract hard skills only (e.g., "Microsoft Excel", "Bookkeeping", "Cisco")
   547→3. DO NOT extract soft skills like "hardworking", "team player" unless explicitly listed as core competencies
   548→4. Calculate years of experience for each cluster

   550→6. DO NOT extract date of birth, nationality, or grade/class
   551→7. DO NOT extract administrative requirements
   552→8. If any field cannot be determined, use null
   553→9. Output ONLY valid JSON
   554→```

   601→# 6. Matching Algorithm
   602→
   603→## 6.1 Core Principles
   604→
   605→| Principle | Implementation |
   606→|-----------|----------------|
   607→| **Inclusive** | Never hides jobs based on missing data |
   608→| **Function-Based** | Primary match is on job function |
   609→| **Ranked** | Best matches appear first |
   610→| **Explainable** | Each match shows why it was recommended |
   611→| **User-Controlled** | Only selected trajectories are matched |
   612→
   613→## 6.2 Step-by-Step Logic
   614→
   615→### Step 1: Function Match (Gateway Filter)
   616→
   617→```javascript
   618→// Next.js API Route - matching logic
   619→function isFunctionMatch(candidate, job) {
   620→    // Only check selected clusters
   621→    const activeClusters = candidate.work_experience.filter(c => c.selected);
   622→    
   623→    for (const cluster of activeClusters) {
   624→        if (cluster.function.toLowerCase() === job.job_function.toLowerCase()) {
   625→            return true;
   626→        }
   627→    }
   628→    return false;
   629→}
   630→```
   631→
   632→**Outcome:**
   633→- If **any** selected cluster matches → Show the job
   634→- If **no** selected cluster matches → Hide the job
   635→
   636→### Step 2: Calculate Match Score (Ranking)
   637→
   638→```javascript
   639→function calculateMatchScore(cluster, job, candidate) {
   640→    let score = 0;
   641→    
   642→    // 1. Job Title Match (40 points)
   643→    const jobTitleLower = job.title.toLowerCase();
   644→    const hasExactMatch = cluster.job_titles.some(
   645→        t => t.toLowerCase() === jobTitleLower
   646→    );
   647→    
   648→    if (hasExactMatch) {
   649→        score += 40;
   650→    } else {
   651→        // Partial match - check for keyword overlap
   652→        const jobKeywords = new Set(job.title.toLowerCase().split(' '));
   653→        const titleKeywords = new Set(
   654→            cluster.job_titles.join(' ').toLowerCase().split(' ')
   655→        );
   656→        const overlap = [...jobKeywords].filter(k => titleKeywords.has(k));
   657→        if (overlap.length > 0) {
   658→            score += Math.min(20, overlap.length * 5);
   659→        }
   660→    }
   661→    
   662→    // 2. Skills Match (35 points)
   663→    const matchedSkills = job.required_skills.filter(
   664→        skill => cluster.skills.some(s => s.toLowerCase() === skill.toLowerCase())
   665→    );
   666→    
   667→    if (job.required_skills.length > 0) {
   668→        const skillPercentage = matchedSkills.length / job.required_skills.length;
   669→        score += skillPercentage * 35;
   670→    }
   671→    
   672→    // 3. Education Match (15 points)
   673→    if (job.required_education.level) {
   674→        const eduScore = compareEducation(
   675→            candidate.education.level,
   676→            job.required_education.level
   677→        );
   678→        score += eduScore * 15;
   679→        
   680→        // Bonus for field relevance (5 points)
   681→        if (job.required_education.field && 
   682→            job.required_education.field !== "Any") {
   683→            const isRelated = isFieldRelated(
   684→                candidate.education.field,
   685→                job.required_education.field
   686→            );
   687→            if (isRelated) score += 5;
   688→        }
   689→    }
   690→    
   691→    // 4. Experience Match (10 points)
   692→    if (job.required_experience_years > 0) {
   693→        const expRatio = Math.min(
   694→            1.0,
   695→            cluster.years_experience / job.required_experience_years
   696→        );
   697→        score += expRatio * 10;
   698→    }
   699→    
   700→    return Math.round(score);
   701→}
   702→```
   703→
   704→### Step 3: Education Level Comparison
   705→
   706→```javascript
   707→const EDUCATION_LEVELS = {
   708→    "PhD": 5,
   709→    "Masters": 4,
   710→    "Bachelor": 3,
   711→    "Diploma": 2,
   712→    "Certificate": 1,
   713→    "None": 0
   714→};
   715→
   716→function compareEducation(candidateLevel, jobRequiredLevel) {
   717→    const candidateValue = EDUCATION_LEVELS[candidateLevel] || 0;
   718→    const requiredValue = EDUCATION_LEVELS[jobRequiredLevel] || 0;
   719→    
   720→    if (candidateValue >= requiredValue) {
   721→        return 1.0;
   722→    } else if (candidateValue === requiredValue - 1) {
   723→        return 0.7;
   724→    } else if (candidateValue === requiredValue - 2) {
   725→        return 0.3;
   726→    } else {
   727→        return 0.0;
   728→    }
   729→}
   730→
   731→function isFieldRelated(candidateField, jobField) {
   732→    // Simplified - could use a predefined mapping or simple string matching
   733→    if (!candidateField || !jobField) return false;
   734→    if (candidateField.toLowerCase() === jobField.toLowerCase()) return true;
   735→    
   736→    // Check if one is contained in the other
   737→    const cLower = candidateField.toLowerCase();
   738→    const jLower = jobField.toLowerCase();
   739→    return cLower.includes(jLower) || jLower.includes(cLower);
   740→}
   741→```
   742→
   743→### Step 4: Generate Explanation
   744→
   745→```javascript
   746→function generateExplanation(cluster, job) {
   747→    const matchedSkills = job.required_skills.filter(
   748→        skill => cluster.skills.some(s => s.toLowerCase() === skill.toLowerCase())
   749→    );
   750→    
   751→    const sampleTitle = cluster.job_titles[0] || "your experience";
   752→    let explanation = `This job matches your experience as a ${sampleTitle}`;
   753→    
   754→    if (matchedSkills.length > 0) {
   755→        const skillList = matchedSkills.slice(0, 3).join(', ');
   756→        explanation += ` and your skills in ${skillList}`;
   757→        if (matchedSkills.length > 3) {
   758→            explanation += ` and ${matchedSkills.length - 3} other skills`;
   759→        }
   760→    }
   761→    
   762→    return explanation;
   763→}
   764→```
   765→
   766→### Step 5: Final Ranking
   767→
   768→```javascript
   769→function rankJobsForCandidate(candidate, allJobs) {
   770→    const rankedJobs = [];
   771→    const activeClusters = candidate.work_experience.filter(c => c.selected);
   772→    
   773→    for (const job of allJobs) {
   774→        let bestScore = 0;
   775→        let bestCluster = null;
   776→        
   777→        for (const cluster of activeClusters) {
   778→            if (cluster.function.toLowerCase() === job.job_function.toLowerCase()) {
   779→                const score = calculateMatchScore(cluster, job, candidate);
   780→                if (score > bestScore) {
   781→                    bestScore = score;
   782→                    bestCluster = cluster;
   783→                }
   784→            }
   785→        }
   786→        
   787→        if (bestCluster) {
   788→            rankedJobs.push({
   789→                job_id: job.job_id,
   790→                match_score: bestScore,
   791→                matched_cluster_id: bestCluster.cluster_id,
   792→                explanation: generateExplanation(bestCluster, job)
   793→            });
   794→        }
   795→    }
   796→    
   797→    // Sort by match score (highest first)
   798→    rankedJobs.sort((a, b) => b.match_score - a.match_score);
   799→    return rankedJobs;
   800→}
   801→```

  1189→## 8.5 Normalization Helpers
  1190→
  1191→```javascript
  1192→// lib/normalize.js
  1193→import { EDUCATION_LEVEL_ENUMS, FUNCTION_ENUMS, SECTOR_ENUMS } from './enums';
  1194→
  1195→export function normalizeEducationLevel(raw) {
  1196→    if (!raw) return 'None';
  1197→    const lower = raw.toLowerCase().trim();
  1198→    
  1199→    for (const [canonical, variations] of Object.entries(EDUCATION_LEVEL_ENUMS)) {
  1200→        for (const variation of variations) {
  1201→            if (lower.includes(variation)) {
  1202→                return canonical;
  1203→            }
  1204→        }
  1205→    }
  1206→    return 'None';
  1207→}
  1208→
  1209→export function normalizeFunction(raw) {
  1210→    if (!raw) return 'Other';
  1211→    const lower = raw.toLowerCase().trim();
  1212→    
  1213→    for (const [canonical, variations] of Object.entries(FUNCTION_ENUMS)) {
  1214→        for (const variation of variations) {
  1215→            if (lower.includes(variation)) {
  1216→                return canonical;
  1217→            }
  1218→        }
  1219→    }
  1220→    return 'Other';
  1221→}
  1222→
  1223→export function normalizeSector(raw) {
  1224→    if (!raw) return 'Other';
  1225→    const lower = raw.toLowerCase().trim();
  1226→    
  1227→    for (const [canonical, variations] of Object.entries(SECTOR_ENUMS)) {
  1228→        for (const variation of variations) {
  1229→            if (lower.includes(variation)) {
  1230→                return canonical;
  1231→            }
  1232→        }
  1233→    }
  1234→    return 'Other';
  1235→}
  1236→
  1237→export function normalizeCandidate(rawJson) {
  1238→    if (!rawJson) return null;
  1239→    
  1240→    // Normalize education
  1241→    if (rawJson.education) {
  1242→        rawJson.education.level = normalizeEducationLevel(rawJson.education.level);
  1243→    }
  1244→    
  1245→    // Normalize work experience clusters
  1246→    if (rawJson.work_experience) {
  1247→        for (const cluster of rawJson.work_experience) {
  1248→            cluster.function = normalizeFunction(cluster.function);
  1249→            
  1250→            // De-duplicate skills
  1251→            if (cluster.skills) {
  1252→                cluster.skills = [...new Set(cluster.skills.map(s => s.trim()))];
  1253→            }
  1254→        }
  1255→    }
  1256→    
  1257→    return rawJson;
  1258→}
  1259→
  1260→export function normalizeJob(rawJson) {
  1261→    if (!rawJson) return null;
  1262→    
  1263→    if (rawJson.job) {
  1264→        rawJson.job.sector = normalizeSector(rawJson.job.sector);
  1265→        rawJson.job.job_function = normalizeFunction(rawJson.job.job_function);
  1266→        if (rawJson.job.required_education) {
  1267→            rawJson.job.required_education.level = normalizeEducationLevel(
  1268→                rawJson.job.required_education.level
  1269→            );
  1270→        }
  1271→    }
  1272→    
  1273→    return rawJson;
  1274→}

  1747→          node-version: '18'

  1754→          DB_USER: ${{ secrets.DB_USER }}
  1755→          DB_PASSWORD: ${{ secrets.DB_PASSWORD }}

  1778→
  1779→### Option C: Traditional Cron Job
  1780→
  1781→```javascript
  1782→// scripts/run-matching.js
  1783→import { query } from '../lib/db.js';
  1784→import { rankJobsForCandidate } from '../lib/matching.js';
  1785→
  1786→async function runMatching() {
  1787→    console.log('Running matching job...');
  1788→    
  1789→    // Get all unmatched jobs (or jobs posted in the last hour)
  1790→    const jobs = await query(
  1791→        `SELECT * FROM jobs 
  1792→         WHERE created_at > DATE_SUB(NOW(), INTERVAL 1 HOUR)`
  1793→    );
  1794→    
  1795→    if (jobs.length === 0) {
  1796→        console.log('No new jobs to match');
  1797→        return;
  1798→    }
  1799→    
  1800→    console.log(`Matching ${jobs.length} new jobs...`);
  1801→    
  1802→    for (const job of jobs) {
  1803→        // Get all candidates
  1804→        const candidates = await query(
  1805→            `SELECT * FROM candidates`
  1806→        );
  1807→        
  1808→        for (const candidate of candidates) {
  1809→            // Get candidate clusters
  1810→            const clusters = await query(
  1811→                `SELECT * FROM candidate_clusters 
  1812→                 WHERE candidate_id = ? AND selected = TRUE`,
  1813→                [candidate.id]
  1814→            );
  1815→            
  1816→            // Calculate matches
  1817→            const matches = rankJobsForCandidate(
  1818→                { ...candidate, work_experience: clusters },
  1819→                [job]
  1820→            );
  1821→            
  1822→            // Store matches
  1823→            for (const match of matches) {
  1824→                await query(
  1825→                    `INSERT INTO job_matches (
  1826→                        candidate_id, job_id, match_score,
  1827→                        matched_cluster_id, explanation
  1828→                    ) VALUES (?, ?, ?, ?, ?)
  1829→                    ON DUPLICATE KEY UPDATE
  1830→                        match_score = VALUES(match_score),
  1831→                        explanation = VALUES(explanation),
  1832→                        updated_at = CURRENT_TIMESTAMP`,
  1833→                    [
  1834→                        candidate.id,
  1835→                        job.id,
  1836→                        match.match_score,
  1837→                        match.matched_cluster_id,
  1838→                        match.explanation
  1839→                    ]
  1840→                );
  1841→            }
  1842→        }
  1843→    }
  1844→    
  1845→    console.log('Matching completed');
  1846→}
  1847→
  1848→runMatching().catch(console.error);
  1849→```

  1961→# Summary of Key Decisions
  1962→
  1963→| Decision | Status | Reasoning |
  1964→|----------|--------|-----------|
  1965→| **Extract with LLM** | ✅ Yes | Handles messy Kenyan CVs better than regex |
  1966→| **Work Experience Clusters** | ✅ Yes | Candidates have multiple career paths |
  1967→| **Limit to 3 Trajectories** | ✅ Yes | Sweet spot between flexibility and focus |
  1968→| **Sector on Candidate** | ❌ Removed | Too ambiguous to extract reliably |
  1969→| **Sector on Job** | ✅ Included | Admin provides it for filters/labels |
  1970→| **Function Matching** | ✅ Required | Primary filter for showing jobs |
  1971→| **Skills Matching** | ✅ Ranking | Determines rank within matching functions |
  1972→| **Education Matching** | ✅ Ranking | Never disqualifies, only boosts rank |
  1973→| **Experience Matching** | ✅ Ranking | Never disqualifies, only boosts rank |
  1974→| **Administrative Requirements** | ❌ Not Matched | Candidate decides if they qualify |
  1975→| **Hard Disqualification** | ❌ Never | No candidate is ever locked out |
  1976→| **Extras (Certifications, Referees)** | ✅ Stored | For resume builder, NOT for matching |
  1977→| **Tech Stack** | Next.js + MySQL | Modern, scalable, cost-effective |
  1978→| **Background Jobs** | Cron Jobs | Simple, reliable, no extra infra |
  1979→| **LLM Cost Model** | Extract Once | $0.001 per CV, $0 for matches |
