    24→    24→# 1. Platform Philosophy
    25→    25→
    26→    26→## Core Principle: Candidate Empowerment, Not Disqualification
    27→    27→
    28→    28→Our platform is designed to **open doors** for job seekers, not close them.
    29→    29→
    30→    30→### The Kenyan Reality:
    31→    31→- A graduate may work multiple jobs for survival
    32→    32→- A BCom graduate might be: Cashier (Today) → Teller (Next Year) → Auditor (Following Year)
    33→    33→- Job seekers have **multiple professional identities**, not one fixed career path
    34→    34→
    35→    35→### What We Do:
    36→    36→- Acknowledge all work experiences as valid
    37→    37→- Present jobs that match **ANY** of the candidate's experiences
    38→    38→- Allow candidates to choose up to **3 career trajectories** to focus on
    39→    39→- Never disqualify candidates based on missing constraints
    40→    40→- Let candidates decide if they meet administrative requirements (e.g., driving license, age)
    41→    41→- Rank jobs so best matches appear first, but all matching jobs are visible
    42→    42→
    43→    43→### What We Don't Do:
    44→    44→- Penalize candidates for having unknown employers
    45→    45→- Lock candidates into a single career path
    46→    46→- Use hard filters that reject candidates
    47→    47→- Extract or rely on ambiguous data like company sector from CVs
    48→    48→- Match on administrative requirements (license, age, nationality, languages)
    49→    49→- Force candidates into rigid career categories
    50→    50→

    53→    53→# 2. System Architecture
    54→    54→
    55→    55→## 2.1 The "Extract Once, Compute Many" Approach
    56→    56→
    57→    57→**Key Decision:** LLM fires **ONCE** for CV parsing and **ONCE** for JD parsing. All matching happens in the database/backend using structured data.
    58→    58→
    59→    59→### Why This Approach:
    60→    60→
    61→    61→| Factor | Traditional (LLM Every Time) | Our Approach (Extract Once) |
    62→    62→|--------|------------------------------|------------------------------|
    63→    63→| **Cost** | $0.001 per match | $0.001 per upload + $0 for matches |
    64→    64→| **Speed** | Slow (LLM latency) | Instant (DB query) |
    65→    65→| **Scalability** | Linear cost scaling | Fixed cost per upload |
    66→    66→| **Accuracy** | Inconsistent (LLM varies) | Deterministic (math) |
    67→    67→

   323→   323→# 4. Data Normalization & Enums
   324→   324→
   325→   325→## 4.1 Why Normalization Matters
   326→   326→
   327→   327→Without normalization, the same concept appears in multiple forms:
   328→   328→
   329→   329→| Raw LLM Output | Issue |
   330→   330→|----------------|-------|
   331→   331→| "BSc", "B.Sc", "Bachelor of Science", "Bachelors" | 4 variations of "Bachelor" |
   332→   332→| "Admin", "Administration", "Office Admin" | 3 variations of "Administration" |
   333→   333→| "Telco", "Telecom", "Telecommunications" | 3 variations of "Telecommunications" |
   334→   334→
   335→   335→**Normalization** maps all variations to a single canonical value.
   336→   336→

   410→   410→## 4.6 Normalization Pipeline
   411→   411→
   412→   412→### Step-by-Step Flow:
   413→   413→
   414→   414→```
   415→   415→LLM Output (Raw JSON)
   416→   416→      |
   417→   417→      ▼
   418→   418→┌─────────────────────────────────────────────────────────────┐
   419→   419→│  normalize_candidate(raw_json):                            │
   420→   420→│                                                             │
   421→   421→│  1. Normalize education.level                              │
   422→   422→│     "BSc" → "Bachelor"                                    │
   423→   423→│                                                             │
   424→   424→│  2. Normalize work_experience[].function                   │
   425→   425→│     "Admin Assistant" → "Administration"                  │
   426→   426→│                                                             │
   427→   427→│  3. De-duplicate skills per cluster                        │
   428→   428→│     ["Excel", "Excel"] → ["Excel"]                        │
   429→   429→│                                                             │
   430→   430→│  4. Calculate years_experience per cluster                 │
   431→   431→│     From start/end dates of jobs                           │
   432→   432→│                                                             │
   433→   433→│  5. Validate and clean strings                             │
   434→   434→└─────────────────────────────────────────────────────────────┘
   435→   435→      |
   436→   436→      ▼
   437→   437→Stored in Database (Clean Enums)
   438→   438→```
   439→   439→
   440→   440→### Implementation:
   441→   441→
   442→   442→```javascript
   443→   443→// Next.js API Route - normalization helper
   444→   444→function normalizeEducationLevel(rawLevel) {
   445→   445→    if (!rawLevel) return null;
   446→   446→    const lower = rawLevel.toLowerCase().trim();
   447→   447→    
   448→   448→    for (const [canonical, variations] of Object.entries(EDUCATION_LEVEL_ENUMS)) {
   449→   449→        for (const variation of variations) {
   450→   450→            if (lower.includes(variation)) {
   451→   451→                return canonical;
   452→   452→            }
   453→   453→        }
   454→   454→    }
   455→   455→    return "None"; // Default
   456→   456→}
   457→   457→
   458→   458→function normalizeFunction(rawFunction) {
   459→   459→    if (!rawFunction) return "Other";
   460→   460→    const lower = rawFunction.toLowerCase().trim();
   461→   461→    
   462→   462→    for (const [canonical, variations] of Object.entries(FUNCTION_ENUMS)) {
   463→   463→        for (const variation of variations) {
   464→   464→            if (lower.includes(variation)) {
   465→   465→                return canonical;
   466→   466→            }
   467→   467→        }
   468→   468→    }
   469→   469→    return "Other";
   470→   470→}
   471→   471→
   472→   472→function normalizeJob(rawJson) {
   473→   473→    // Normalize fields
   474→   474→    rawJson.job.job_function = normalizeFunction(rawJson.job.job_function);
   475→   475→    rawJson.job.sector = normalizeSector(rawJson.job.sector);
   476→   476→    rawJson.job.required_education.level = normalizeEducationLevel(
   477→   477→        rawJson.job.required_education.level

   601→   601→# 6. Matching Algorithm
   602→   602→
   603→   603→## 6.1 Core Principles
   604→   604→
   605→   605→| Principle | Implementation |
   606→   606→|-----------|----------------|
   607→   607→| **Inclusive** | Never hides jobs based on missing data |
   608→   608→| **Function-Based** | Primary match is on job function |
   609→   609→| **Ranked** | Best matches appear first |
   610→   610→| **Explainable** | Each match shows why it was recommended |
   611→   611→| **User-Controlled** | Only selected trajectories are matched |
   612→   612→
   613→   613→## 6.2 Step-by-Step Logic
   614→   614→
   615→   615→### Step 1: Function Match (Gateway Filter)
   616→   616→
   617→   617→```javascript
   618→   618→// Next.js API Route - matching logic
   619→   619→function isFunctionMatch(candidate, job) {
   620→   620→    // Only check selected clusters
   621→   621→    const activeClusters = candidate.work_experience.filter(c => c.selected);
   622→   622→    
   623→   623→    for (const cluster of activeClusters) {
   624→   624→        if (cluster.function.toLowerCase() === job.job_function.toLowerCase()) {
   625→   625→            return true;
   626→   626→        }
   627→   627→    }
   628→   628→    return false;
   629→   629→}
   630→   630→```
   631→   631→
   632→   632→**Outcome:**
   633→   633→- If **any** selected cluster matches → Show the job
   634→   634→- If **no** selected cluster matches → Hide the job
   635→   635→
   636→   636→### Step 2: Calculate Match Score (Ranking)
   637→   637→
   638→   638→```javascript
   639→   639→function calculateMatchScore(cluster, job, candidate) {
   640→   640→    let score = 0;
   641→   641→    
   642→   642→    // 1. Job Title Match (40 points)
   643→   643→    const jobTitleLower = job.title.toLowerCase();
   644→   644→    const hasExactMatch = cluster.job_titles.some(
   645→   645→        t => t.toLowerCase() === jobTitleLower
   646→   646→    );
   647→   647→    
   648→   648→    if (hasExactMatch) {
   649→   649→        score += 40;
   650→   650→    } else {
   651→   651→        // Partial match - check for keyword overlap
   652→   652→        const jobKeywords = new Set(job.title.toLowerCase().split(' '));
   653→   653→        const titleKeywords = new Set(
   654→   654→            cluster.job_titles.join(' ').toLowerCase().split(' ')
   655→   655→        );
   656→   656→        const overlap = [...jobKeywords].filter(k => titleKeywords.has(k));
   657→   657→        if (overlap.length > 0) {
   658→   658→            score += Math.min(20, overlap.length * 5);
   659→   659→        }
   660→   660→    }
   661→   661→    
   662→   662→    // 2. Skills Match (35 points)
   663→   663→    const matchedSkills = job.required_skills.filter(
   664→   664→        skill => cluster.skills.some(s => s.toLowerCase() === skill.toLowerCase())
   665→   665→    );
   666→   666→    
   667→   667→    if (job.required_skills.length > 0) {
   668→   668→        const skillPercentage = matchedSkills.length / job.required_skills.length;
   669→   669→        score += skillPercentage * 35;
   670→   670→    }
   671→   671→    
   672→   672→    // 3. Education Match (15 points)
   673→   673→    if (job.required_education.level) {
   674→   674→        const eduScore = compareEducation(
   675→   675→            candidate.education.level,
   676→   676→            job.required_education.level
   677→   677→        );
   678→   678→        score += eduScore * 15;
   679→   679→        
   680→   680→        // Bonus for field relevance (5 points)
   681→   681→        if (job.required_education.field && 
   682→   682→            job.required_education.field !== "Any") {
   683→   683→            const isRelated = isFieldRelated(
   684→   684→                candidate.education.field,
   685→   685→                job.required_education.field
   686→   686→            );
   687→   687→            if (isRelated) score += 5;
   688→   688→        }
   689→   689→    }
   690→   690→    
   691→   691→    // 4. Experience Match (10 points)
   692→   692→    if (job.required_experience_years > 0) {
   693→   693→        const expRatio = Math.min(
   694→   694→            1.0,
   695→   695→            cluster.years_experience / job.required_experience_years
   696→   696→        );
   697→   697→        score += expRatio * 10;
   698→   698→    }
   699→   699→    
   700→   700→    return Math.round(score);
   701→   701→}
   702→   702→```
   703→   703→
   704→   704→### Step 3: Education Level Comparison
   705→   705→
   706→   706→```javascript
   707→   707→const EDUCATION_LEVELS = {
   708→   708→    "PhD": 5,
   709→   709→    "Masters": 4,
   710→   710→    "Bachelor": 3,
   711→   711→    "Diploma": 2,
   712→   712→    "Certificate": 1,
   713→   713→    "None": 0
   714→   714→};
   715→   715→
   716→   716→function compareEducation(candidateLevel, jobRequiredLevel) {
   717→   717→    const candidateValue = EDUCATION_LEVELS[candidateLevel] || 0;
   718→   718→    const requiredValue = EDUCATION_LEVELS[jobRequiredLevel] || 0;
   719→   719→    
   720→   720→    if (candidateValue >= requiredValue) {
   721→   721→        return 1.0;
   722→   722→    } else if (candidateValue === requiredValue - 1) {
   723→   723→        return 0.7;
   724→   724→    } else if (candidateValue === requiredValue - 2) {
   725→   725→        return 0.3;
   726→   726→    } else {
   727→   727→        return 0.0;
   728→   728→    }
   729→   729→}
   730→   730→
   731→   731→function isFieldRelated(candidateField, jobField) {
   732→   732→    // Simplified - could use a predefined mapping or simple string matching
   733→   733→    if (!candidateField || !jobField) return false;
   734→   734→    if (candidateField.toLowerCase() === jobField.toLowerCase()) return true;
   735→   735→    
   736→   736→    // Check if one is contained in the other
   737→   737→    const cLower = candidateField.toLowerCase();
   738→   738→    const jLower = jobField.toLowerCase();
   739→   739→    return cLower.includes(jLower) || jLower.includes(cLower);
   740→   740→}
   741→   741→```
   742→   742→
   743→   743→### Step 4: Generate Explanation
   744→   744→
   745→   745→```javascript
   746→   746→function generateExplanation(cluster, job) {
   747→   747→    const matchedSkills = job.required_skills.filter(
   748→   748→        skill => cluster.skills.some(s => s.toLowerCase() === skill.toLowerCase())
   749→   749→    );
   750→   750→    
   751→   751→    const sampleTitle = cluster.job_titles[0] || "your experience";
   752→   752→    let explanation = `This job matches your experience as a ${sampleTitle}`;
   753→   753→    
   754→   754→    if (matchedSkills.length > 0) {
   755→   755→        const skillList = matchedSkills.slice(0, 3).join(', ');
   756→   756→        explanation += ` and your skills in ${skillList}`;
   757→   757→        if (matchedSkills.length > 3) {
   758→   758→            explanation += ` and ${matchedSkills.length - 3} other skills`;
   759→   759→        }
   760→   760→    }
   761→   761→    
   762→   762→    return explanation;
   763→   763→}
   764→   764→```
   765→   765→
   766→   766→### Step 5: Final Ranking
   767→   767→
   768→   768→```javascript
   769→   769→function rankJobsForCandidate(candidate, allJobs) {
   770→   770→    const rankedJobs = [];
   771→   771→    const activeClusters = candidate.work_experience.filter(c => c.selected);
   772→   772→    
   773→   773→    for (const job of allJobs) {
   774→   774→        let bestScore = 0;
   775→   775→        let bestCluster = null;
   776→   776→        
   777→   777→        for (const cluster of activeClusters) {
   778→   778→            if (cluster.function.toLowerCase() === job.job_function.toLowerCase()) {
   779→   779→                const score = calculateMatchScore(cluster, job, candidate);
   780→   780→                if (score > bestScore) {
   781→   781→                    bestScore = score;
   782→   782→                    bestCluster = cluster;
   783→   783→                }
   784→   784→            }
   785→   785→        }
   786→   786→        
   787→   787→        if (bestCluster) {
   788→   788→            rankedJobs.push({
   789→   789→                job_id: job.job_id,
   790→   790→                match_score: bestScore,
   791→   791→                matched_cluster_id: bestCluster.cluster_id,
   792→   792→                explanation: generateExplanation(bestCluster, job)
   793→   793→            });
   794→   794→        }
   795→   795→    }
   796→   796→    
   797→   797→    // Sort by match score (highest first)
   798→   798→    rankedJobs.sort((a, b) => b.match_score - a.match_score);
   799→   799→    return rankedJobs;
   800→   800→}
   801→   801→```

  1192→  1192→// lib/normalize.js
  1193→  1193→import { EDUCATION_LEVEL_ENUMS, FUNCTION_ENUMS, SECTOR_ENUMS } from './enums';
  1194→  1194→
  1195→  1195→export function normalizeEducationLevel(raw) {
  1196→  1196→    if (!raw) return 'None';
  1197→  1197→    const lower = raw.toLowerCase().trim();
  1198→  1198→    
  1199→  1199→    for (const [canonical, variations] of Object.entries(EDUCATION_LEVEL_ENUMS)) {
  1200→  1200→        for (const variation of variations) {
  1201→  1201→            if (lower.includes(variation)) {
  1202→  1202→                return canonical;
  1203→  1203→            }
  1204→  1204→        }
  1205→  1205→    }
  1206→  1206→    return 'None';
  1207→  1207→}
  1208→  1208→
  1209→  1209→export function normalizeFunction(raw) {
  1210→  1210→    if (!raw) return 'Other';
  1211→  1211→    const lower = raw.toLowerCase().trim();
  1212→  1212→    
  1213→  1213→    for (const [canonical, variations] of Object.entries(FUNCTION_ENUMS)) {
  1214→  1214→        for (const variation of variations) {
  1215→  1215→            if (lower.includes(variation)) {
  1216→  1216→                return canonical;
  1217→  1217→            }
  1218→  1218→        }
  1219→  1219→    }
  1220→  1220→    return 'Other';
  1221→  1221→}
  1222→  1222→
  1223→  1223→export function normalizeSector(raw) {
  1224→  1224→    if (!raw) return 'Other';
  1225→  1225→    const lower = raw.toLowerCase().trim();
  1226→  1226→    
  1227→  1227→    for (const [canonical, variations] of Object.entries(SECTOR_ENUMS)) {
  1228→  1228→        for (const variation of variations) {
  1229→  1229→            if (lower.includes(variation)) {
  1230→  1230→                return canonical;
  1231→  1231→            }
  1232→  1232→        }
  1233→  1233→    }
  1234→  1234→    return 'Other';
  1235→  1235→}
  1236→  1236→
  1237→  1237→export function normalizeCandidate(rawJson) {
  1238→  1238→    if (!rawJson) return null;
  1239→  1239→    
  1240→  1240→    // Normalize education
  1241→  1241→    if (rawJson.education) {
  1242→  1242→        rawJson.education.level = normalizeEducationLevel(rawJson.education.level);
  1243→  1243→    }
  1244→  1244→    
  1245→  1245→    // Normalize work experience clusters
  1246→  1246→    if (rawJson.work_experience) {
  1247→  1247→        for (const cluster of rawJson.work_experience) {
  1248→  1248→            cluster.function = normalizeFunction(cluster.function);
  1249→  1249→            
  1250→  1250→            // De-duplicate skills
  1251→  1251→            if (cluster.skills) {
  1252→  1252→                cluster.skills = [...new Set(cluster.skills.map(s => s.trim()))];
  1253→  1253→            }
  1254→  1254→        }
  1255→  1255→    }
  1256→  1256→    
  1257→  1257→    return rawJson;

  1271→  1271→    }

  1774→  1774→        return Response.json({ error: error.message }, { status: 500 });
  1775→  1775→    }
  1776→  1776→}

  1779→  1779→### Option C: Traditional Cron Job
  1780→  1780→
  1781→  1781→```javascript
  1782→  1782→// scripts/run-matching.js
  1783→  1783→import { query } from '../lib/db.js';
  1784→  1784→import { rankJobsForCandidate } from '../lib/matching.js';
  1785→  1785→
  1786→  1786→async function runMatching() {
  1787→  1787→    console.log('Running matching job...');
  1788→  1788→    
  1789→  1789→    // Get all unmatched jobs (or jobs posted in the last hour)
  1790→  1790→    const jobs = await query(
  1791→  1791→        `SELECT * FROM jobs 
  1792→  1792→         WHERE created_at > DATE_SUB(NOW(), INTERVAL 1 HOUR)`
  1793→  1793→    );
  1794→  1794→    
  1795→  1795→    if (jobs.length === 0) {
  1796→  1796→        console.log('No new jobs to match');
  1797→  1797→        return;
  1798→  1798→    }
  1799→  1799→    
  1800→  1800→    console.log(`Matching ${jobs.length} new jobs...`);
  1801→  1801→    
  1802→  1802→    for (const job of jobs) {
  1803→  1803→        // Get all candidates
  1804→  1804→        const candidates = await query(
  1805→  1805→            `SELECT * FROM candidates`
  1806→  1806→        );
  1807→  1807→        
  1808→  1808→        for (const candidate of candidates) {
  1809→  1809→            // Get candidate clusters
  1810→  1810→            const clusters = await query(
  1811→  1811→                `SELECT * FROM candidate_clusters 
  1812→  1812→                 WHERE candidate_id = ? AND selected = TRUE`,
  1813→  1813→                [candidate.id]
  1814→  1814→            );
  1815→  1815→            
  1816→  1816→            // Calculate matches
  1817→  1817→            const matches = rankJobsForCandidate(
  1818→  1818→                { ...candidate, work_experience: clusters },
  1819→  1819→                [job]
  1820→  1820→            );
  1821→  1821→            
  1822→  1822→            // Store matches
  1823→  1823→            for (const match of matches) {
  1824→  1824→                await query(
  1825→  1825→                    `INSERT INTO job_matches (
  1826→  1826→                        candidate_id, job_id, match_score,
  1827→  1827→                        matched_cluster_id, explanation
  1828→  1828→                    ) VALUES (?, ?, ?, ?, ?)
  1829→  1829→                    ON DUPLICATE KEY UPDATE
  1830→  1830→                        match_score = VALUES(match_score),
  1831→  1831→                        explanation = VALUES(explanation),
  1832→  1832→                        updated_at = CURRENT_TIMESTAMP`,
  1833→  1833→                    [
  1834→  1834→                        candidate.id,
  1835→  1835→                        job.id,
  1836→  1836→                        match.match_score,
  1837→  1837→                        match.matched_cluster_id,
  1838→  1838→                        match.explanation
  1839→  1839→                    ]
  1840→  1840→                );
  1841→  1841→            }
  1842→  1842→        }
  1843→  1843→    }
  1844→  1844→    
  1845→  1845→    console.log('Matching completed');
  1846→  1846→}
  1847→  1847→
  1848→  1848→runMatching().catch(console.error);
  1849→  1849→```

  1961→  1961→# Summary of Key Decisions
  1962→  1962→
  1963→  1963→| Decision | Status | Reasoning |
  1964→  1964→|----------|--------|-----------|
  1965→  1965→| **Extract with LLM** | ✅ Yes | Handles messy Kenyan CVs better than regex |
  1966→  1966→| **Work Experience Clusters** | ✅ Yes | Candidates have multiple career paths |
  1967→  1967→| **Limit to 3 Trajectories** | ✅ Yes | Sweet spot between flexibility and focus |
  1968→  1968→| **Sector on Candidate** | ❌ Removed | Too ambiguous to extract reliably |
  1969→  1969→| **Sector on Job** | ✅ Included | Admin provides it for filters/labels |
  1970→  1970→| **Function Matching** | ✅ Required | Primary filter for showing jobs |
  1971→  1971→| **Skills Matching** | ✅ Ranking | Determines rank within matching functions |
  1972→  1972→| **Education Matching** | ✅ Ranking | Never disqualifies, only boosts rank |
  1973→  1973→| **Experience Matching** | ✅ Ranking | Never disqualifies, only boosts rank |
  1974→  1974→| **Administrative Requirements** | ❌ Not Matched | Candidate decides if they qualify |
  1975→  1975→| **Hard Disqualification** | ❌ Never | No candidate is ever locked out |
  1976→  1976→| **Extras (Certifications, Referees)** | ✅ Stored | For resume builder, NOT for matching |
  1977→  1977→| **Tech Stack** | Next.js + MySQL | Modern, scalable, cost-effective |
  1978→  1978→| **Background Jobs** | Cron Jobs | Simple, reliable, no extra infra |
  1979→  1979→| **LLM Cost Model** | Extract Once | $0.001 per CV, $0 for matches |
