# Vercel's Python runtime reads this file from the api/ directory.

#   MissingDependencyException when given a PDF.

# transformers / azure-ai for image & audio transcription — heavy ML deps

#
# flask — WSGI framework; Vercel's Python runtime auto-detects `app = Flask(...)`
# werkzeug — pinned security baseline (Flask transitive dep).
